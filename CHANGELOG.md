# Changelog

## 0.1.0 (2026-10-04)

- New skill `resume-enhancer`: setup questions, a facts file, an audit against 28 house-style
  rules, a change table to approve, and a one-page render.
- Scripts: `fill_template.py` (dense or roomy look), `render.sh` (page limit 1 or 2, clear
  exits for no LaTeX and missing packages), `fill_check.py` (line fill and wraps).
- Manifests for the same tools as skill-kit. Tests and `validate.py` run in CI.
